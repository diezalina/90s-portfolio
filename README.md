# A look into the past

A simple website built with **HTML, CSS, and JavaScript**, inspired by the aesthetics of the late 90s and early 2000s internet.

The design embraces retro web elements, nostalgic visuals, and a playful, old-school digital atmosphere.

Really missing the old internet from when I started using a windows XP computer!

## Built With
- HTML
- CSS
- JavaScript

## Inspiration
The early days when MSN and chatrooms were a thing in the internet; anyone could code their own with these simple tools and create blogs or other.

Inspired to showcase a bit of my coding experience along with artistic projects, an insight into the things I like on the internet and that I try to keep today!
